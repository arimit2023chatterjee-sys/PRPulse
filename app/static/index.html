GitHub Webhook Integration

Configure your GitHub repositories to automatically trigger PR reviews on every pull request event.

Interactive Setup Walkthrough

1

Set Payload URL in GitHub

Navigate to your repository -> Settings -> Webhooks -> Add webhook.

2

Select Content Type

application/json

⚠️ Do not leave as form-urlencoded. Our engine expects JSON payloads.

3

Configure Webhook Secret (HMAC SHA-256)

GitHub uses this secret to sign the `X-Hub-Signature-256` header to ensure only authentic requests are executed.

4

Choose Event Triggers

Select: "Let me select individual events"

Check: ☑️ Pull requests (Actions: opened, synchronize, reopened)

Webhook Status

Endpoint Status: Listening
HMAC Verification: Enforced
Auto-Post to GitHub: Disabled

Testing Delivery:

GitHub automatically sends a ping event when you create the webhook. Check the "Recent Deliveries" section in GitHub to confirm the 200 OK response.
