Enforced Verification Gates
1. Diff Sanitation & Mapping PRE-PASS

Excludes binaries, lockfiles, and minified bundles. Calculates exact 1-indexed target line anchors.

2. Deterministic AST Security Pass STATIC

High-entropy secret regexes (AWS, PATs, private keys) + Python AST inspection (`subprocess(shell=True)`, `eval`, SQL string interpolation, bare `except:`).

3. Schema-Constrained Review LLM / RULES

Evaluates N+1 database queries, unhandled NoneTypes, missing HTTP timeouts, and resource leaks strictly via Pydantic v2 schemas.

4. GitHub Status Reporting PUBLISH

Submits formal PR review events (`APPROVE`, `REQUEST_CHANGES`, `COMMENT`) directly to the GitHub REST API.

Security Ingestion Parameters
SIGNATURE_CHECK HMAC-SHA256
ENDPOINT_STATUS 200 LISTENING
SECURITY_ACTION BLOCK_ON_401
